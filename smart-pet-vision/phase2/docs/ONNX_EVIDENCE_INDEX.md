## Reproduce (existing tools; CPU, minutes, no training; needs the private detector weights)

```bash
cd smart-pet-vision/phase2
# export a new candidate next to the weights (never overwrites an existing export)
PYTHONPATH=src python -c "from pathlib import Path; from spv.deploy import export_yolo_onnx; print(export_yolo_onnx(Path('runs/detect/yolo11s_det/weights/best.pt'), 640, Path('scratch/best_candidate.onnx')))"
# 1. raw-head parity (A9b protocol: seed 0, 4 inputs)
PYTHONPATH=src python -c "from pathlib import Path; from spv.deploy import yolo_parity; print(yolo_parity(Path('runs/detect/yolo11s_det/weights/best.pt'), Path('scratch/best_candidate.onnx'), 640))"
# 1a. per-channel diagnosis
PYTHONPATH=src python tools/onnx_channel_diagnosis.py --weights runs/detect/yolo11s_det/weights/best.pt --onnx scratch/best_candidate.onnx --out scratch/onnx_channels.json
```

Rows 2–4 come from Colab runs: row 3 and row 1a from notebook 11 (`11_phase2_gap_experiments`, saved
as `P2_gap_experiments_20261102.json`), row 4 from notebook 05; the final-detection check is
`spv.deploy.yolo_parity_real`, used by notebooks 05 and 09. The notebooks in `notebooks/` are saved
without outputs; executed copies are listed in the release package index. Oxford test images and,
for row 2b, the private team photos are needed. Results of a new run are new evidence with their own
date; they do not replace the files above and do not change A9b.
